# Lobby art (saved, not loaded)

The office-lobby scene used up to M1.8, kept in case the game goes back to it.
- `scene.js`: the lobby room (walls, windows, lifts, TV, poster, clock, lamps, bench) and all scene effects of that time.
- `sprites.js`: machines, customers and room pieces of that time.
- `core-world.js`: the data file of that time (see `DATA.world` for the lobby layout: lifts at x 58 and 424).

To use it again, copy these back over `js/scene.js` / `js/sprites.js` and restore `DATA.world` in `js/data/core.js`.
