Made by tools/export.html from the game's own drawing code (the game still draws everything in code).
1x = real pixel size (1 world pixel = 1 image pixel). 4x = the same, 4 times bigger, for easy viewing.
Clear (transparent) backgrounds, cropped to each piece.

The park is 480 x 270. Machines stand on the ground line at y 200; people stand with their feet on their y.
park-*: the whole park. park-*-no-trees: without the cherry trees. trees-*: only the trees (put them on top).
Night lighting (dark overlay, lamp glow) is added by the game on top, so park-night is not darkened here.
Rebuild: start tools/devserver.py 8741, open http://localhost:8741/tools/export.html, run exportAll() in the console.
